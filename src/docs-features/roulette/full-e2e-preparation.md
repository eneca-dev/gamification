## Выполненная сквозная приёмка

1. Вход тестового пользователя; отказ без авторизации и для недопущенного пользователя.
2. Подтверждение → настоящий ход → один результат и одна проводка → правильный баланс БД/UI.
3. Повтор запроса и перезагрузка не создают второй ход.
4. Потеря ответа после подтверждённого COMMIT → восстановление исходной операции и актуального баланса.
5. Выключатель запрещает новые ходы.

Все пять пунктов пройдены командой `node scripts/test-roulette-wsl-e2e.mjs` в Chromium, 1280×900. Настоящие локальные Auth/SSR-сессия, server actions, PostgREST и PostgreSQL; БД проверена независимым соединением. Обычный ход: 1000→1200, одна проводка +200. Потерянный ответ оборван после подтверждённого COMMIT: исходный результат 1000→0, затем отдельное синтетическое начисление +37; восстановление сохранило старый результат, а UI и серверный кэш показали текущие 37. Второй ход не создан. Прямой POST без сессии отдельно отклонён с 307 на `/login`, бизнес-данные неизменны (`anonymous-action-results.json`).

Внешних запросов в прогоне не обнаружено. Серверный сетевой ограничитель и CSP запрещают внешние назначения. Тестовый вход добавлен только в игнорируемую копию приложения. После E2E локальный выключатель подтверждён как false. Общий lint: 0 ошибок, 49 предупреждений; production build с проверкой TypeScript успешен.
