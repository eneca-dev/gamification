# Изолированный браузерный стенд рулетки

## Запуск

Из корня: `node scripts/roulette-browser-server.mjs`, затем http://127.0.0.1:4179.
Это отдельный стенд; localhost:3000 по-прежнему использует рабочий Supabase.

Параметры URL:

- `?sector=x2`: результат ×2; также plus500, plus200, plus100, plus50, zero1, zero2.
- `?scenario=disabled`: выключатель; zero, impersonating, loading, balance-error, state-error — ограничения и ошибки.
- `?scenario=lost-response`: синтетический результат сохранён, ответ потерян; перезагрузка и восстановление прежнего хода.
- `?scenario=balance-after-error`: результат выполнен, чтение актуального баланса не удалось.

Результаты сохраняются в localStorage отдельного origin. Для нового ручного прогона очистить данные сайта 127.0.0.1:4179. Рабочий аккаунт не требуется.

## Автоматические проверки

Команда: `node scripts/test-roulette-browser.mjs`.
18 сценариев на 5 ширинах: 360, 768, 1280, 1920, 2560 px. Запускать отдельно от build/Vitest: одновременная нагрузка на этой машине приводила к таймаутам.

Проверяются семь исходов и конечные углы колеса, анимация/reduced motion, риск, клавиатура/отмена, границы диалога, переполнение, ограничения, ошибки, восстановление после reload, независимость исторического/текущего баланса и гонка ответов. Ожидаемые суммы и углы заданы отдельно от реализации.

Отчёт: `test-results/roulette-browser-results.json`; скриншоты: `test-results/roulette-browser/`. Существующий `playwright.config.ts` и его запреты на рабочую БД сохранены.

## Изоляция и ограничения

Настоящие компоненты, hooks, query keys, фабрики мутаций/запросов и pending storage. Server Actions заменены только в тестовой сборке синтетическими функциями; провайдеры Supabase/realtime исключены. Нет подключения к PostgreSQL и интеграциям.

Сборка не читает .env (envDir: false), не публикует public/исходники. Сервер слушает только 127.0.0.1:4179 и отдаёт сгенерированные HTML/CSS/JS; занятый порт останавливает запуск. CSP запрещает сетевые подключения, внешние шрифты исключены. Playwright дополнительно блокирует внешние origins.

Это приёмка клиентского поведения с синтетической серверной границей. Она не подтверждает Auth/PostgREST, реальный COMMIT, серверный кэш Next.js, Store App Router или доставку Airtable/Teams. Полная сквозная приёмка остаётся отдельным этапом.

## Найденный дефект

Вращение SVG расширяло прокручиваемую область на 360 px. В RouletteWheel добавлен overflow-hidden на оболочку; расчёты и поведение операций не изменены. Проверяется отсутствие переполнения после каждого из семи исходов.
