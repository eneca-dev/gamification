# Полная отрисовка коллекции Бимо: пакеты

План согласован пользователем 2026-11-06. Основная реализация и ограничения:
[план приложения](plan.md), [стандарт графики](graphics-standard.md).

## Порядок работы

Одна вещь за пакет, до 5 итоговых WebP. Простые фоны допускают 2–3 изображения
за пакет. После каждого пакета показать результат пользователю, исправить
замечания и только после визуального одобрения переходить к следующему.
Готовность графики не разрешает публикацию товара. Статусы и цены не менять.
Исключение, явно согласованное 2026-11-10: удалить только неиспользованный
черновик синей шапочки после проверки связей через Supabase MCP.

## Проверка каждого пакета

1. Статичная проба и соответствие утверждённому образу.
2. Подготовка портрета/трёх листов или статичного фона согласно типу вещи.
3. Размеры, прозрачность, отсутствие обрезанных краёв, 16 поз и совмещение слоёв.
4. Подключение к локальной примерке в магазине и карточке, без публикации/покупки черновика. Отдельная тестовая страница удалена.
5. Проверка пользователем в обычном размере и с увеличением браузера ×2, затем исправления и одобрение.

Для аксессуаров дополнительно проверить лицо, уши, повороты головы и поднятые
лапы. Для фонов — место под презентацию, хвост и кристалл. После всех пакетов
проверить сочетания, единообразие карточек, загрузку и объём файлов.
Неподключённые варианты сохранять в игнорируемом архиве, не удалять.
