# Фоны Бимо и фильтр админки

План утверждён пользователем 15.11.2026. Подготовить все фоны, кроме персикового.
Пользователь разрешил загрузку через действующий генератор админки. Прямые
обращения агента к Supabase выполняются через Supabase MCP.

## Результат

Фильтр «Бимо» с динамическим счётчиком в `/admin/products`. Общий импортер
поддерживает обновление графики существующего товара. Семь новых фонов образуют
единую коллекцию в мультяшном стиле текущего персонажа, с полукруглым арочным
силуэтом, прозрачными полями и общей композицией. Пользователь уточнил стиль
и выбрал полукруг вместо прямоугольника во время подготовки первого образца.

Базовый мятный фон доступен через пустой слот. Шесть товарных фонов обновляют
записи `background.lavender`, `background.clouds`, `background.office`,
`background.green_courtyard`, `background.beach`, `background.starry_evening`.
Товары сохраняют идентификаторы, названия, цены и статус черновика.

## Этапы

1. Фильтр в админке. Один список отображаемых фильтров для измерителя,
   видимых кнопок и меню переполнения. Проверить счётчик, поиск, карточки,
   список и выделение видимых товаров.
2. Общая композиция. Сначала подготовить мятную студию и проверить фон вместе
   с текущим Бимо. Холст 6:5, результат импорта 600×500, место для стоп
   учитывает действующее положение модели `(44,2)`. Рисунки создаются встроенным imagegen.
3. Создать остальные шесть фонов с теми же рамкой, стилем и опорой.
   Сохранить выбранные исходники и точные промпты внутри проекта.
4. Дополнить действующий генератор обновлением графики. Сервер проверяет
   выбранный товар и тип вещи, сохраняет изображения под уникальным путём,
   условным атомарным обновлением переключает `art`, `art_version`, `fit`.
   При неопределённом результате ресурсы сохраняются до выяснения состояния.
   Подготовить шесть файлов для загрузки через интерфейс админки. По уточнению
   пользователя ручную загрузку выполняет пользователь, если расширение
   блокирует автоматический выбор локального файла.
5. Выполнить проверки типов, линтера, сборки, импорта и частичных сбоев.
   Проверить все фоны с пиджаком и худи, три реакции, карточки и узкий экран.

## Прогресс

- Этап 1 завершён. В браузере проверены «Бимо (17)», поиск, пустой результат,
  выделение одного видимого товара, список и карточки. На ширине 390 px
  фильтр доступен в меню переполнения, меню проверено клавиатурой.
- Этапы 2–3 завершены. Сохранены семь принятых исходников ImageGen, точные
  промпты, семь PNG 600×500 и lossless WebP базового мятного фона.
- Этап 4 завершён в части кода. GET читает выбранный фон и возвращает revision.
  PATCH обновляет только `art`, `art_version`, `fit` с условием по прежнему
  содержимому и `is_released=false`. Статус публикации определяется каталогом
  Бимо. Доступность товара редактируется отдельно. Новые файлы имеют уникальные
  адреса. При потере ответа проверяется результат, при неопределённости файл
  сохраняется. Проверено 27 сценариев с подставными ответами. Реальная загрузка
  шести файлов передана пользователю по его уточнению.
- Этап 5 завершён для доступных проверок. Прошли TypeScript, ESLint и production
  сборка вне песочницы. Первый запуск Turbopack внутри песочницы остановился
  при запуске дочернего процесса PostCSS. Прошли 1523 позы, 5647 пикселей симметрии,
  37 проверок импорта, 15 сценариев создания, 27 сценариев обновления и проверки
  обоих читателей каталога. Для фонов прошли семь импортов с сохранением видимых
  пикселей и альфа-канала, 56 JSX-сборок с пиджаком и худи, семь растровых превью.
  Коллекция осмотрена вместе с текущим Бимо.

В браузере проверены выбранный товар «Уютный офис», чтение его черновика,
блокировка сохранения до загрузки файла и три реакции на новом базовом фоне.
На ширине 390 px ширина документа 385 px, ширина формы и scrollWidth равны 355 px.
Клавиатурный фокус делает кнопку обновления видимой. Временный viewport сброшен.

Автоматическая передача локального файла остановлена расширением с требованием
Allow access to file URLs. Пользователь выбрал обычную ручную загрузку файлов.
Чтение через Supabase MCP 16.11.2026 подтвердило шесть
целевых записей версии 0 с `art=null`, все невыпущенные. Новые товарные картинки
ожидают ручного сохранения, реальный PATCH с записью в Supabase пока не проверен.

## Инструменты и приёмка

Художественные источники находятся в `art/backgrounds/`. Рабочие образцы для
импортера находятся в `public/bimo/backgrounds-v4/`. Бесплатный фон использует
`/bimo/backgrounds-v4/mint.webp`. Промпты находятся в `art/backgrounds/prompts.json`.
Кратковременные рендеры и результаты проверок создаются в `tmp/rig`.

После итоговой проверки удалены 18 временных файлов, 3 447 291 байт.
Удалена дублирующая копия мятного WebP по прежнему пути после проверки совпадения
SHA-256 с текущим файлом. Все восемь сохраняемых файлов коллекции проверены
контрольными суммами после очистки.

Обзор коллекции и снимок проверенной формы сохранены в каталоге артефактов
текущей сессии как `bimo-backgrounds-preview.png` и `bimo-admin-background.jpg`.

`build-backgrounds.mjs` воспроизводит упаковку принятых исходников.
`verify-backgrounds.mjs` проверяет коллекцию настоящим валидатором и рендерером.
`verify-update.mjs` проверяет настоящий GET/PATCH с подставными БД и Storage.
Это локальные инструменты подготовки и QA. В приложении работают существующий
импортер, его форма и API.

При проверке сравнения PNG/WebP нормализуются RGB полностью прозрачных пикселей.
WebP может обнулять эти значения. Видимые пиксели и весь альфа-канал сравниваются
точно. Первый вариант проверки пытался вывести большой Buffer-diff и исчерпал
память Node.js. После исправления сравнения проверка коллекции прошла.

## Ручная загрузка

1. Открыть `/admin/products`, выбрать «Бимо», найти нужный фон по названию.
2. Нажать кнопку с иконкой загрузки изображения, подсказка «Обновить графику Бимо».
3. В поле «Фон» выбрать соответствующий PNG из
   `D:\gamification-1\public\bimo\backgrounds-v4`. Файлы уже имеют нужный холст.
4. Проверить предпросмотр и реакции, нажать «Обновить графику».
5. Открыть тот же фон повторно и проверить сохранённую картинку.

| Товар | Файл |
| --- | --- |
| Бимо · Уютный офис | `office.png` |
| Бимо · Лавандовый | `lavender.png` |
| Бимо · Над облаками | `clouds.png` |
| Бимо · Зелёный дворик | `green-courtyard.png` |
| Бимо · Пляж | `beach.png` |
| Бимо · Звёздный вечер | `starry-evening.png` |

Мятный фон уже подключён как бесплатный базовый вариант через `DEFAULT_LOOK`.

Браузерная проверка выполняется через подключённую вкладку приложения.
Git используется только для чтения.
